3. Log Inspection & Debugging (Production Standard)

  • head -n 10 file.txt: Top 10 lines view karta hai.
  • tail -n 10 file.txt: Bottom 10 lines view karta hai.
  • tail -f file.log: Real-time live log stream monitor karta hai (Ctrl + C to exit).
  • less file.log: Memory-safe page-by-page reader for heavy files (q to exit).
  • grep -n "keyword" file.log: Pattern match karke line numbers display karta hai.

4. Permissions & Shell Scripting

  • Permission Format: [type][user][group][others] (e.g. -rwxr-xr-x)
  • Octal Calculation: Read (4) + Write (2) + Execute (1) = 7 (Full Access)
  • Executable Script: chmod +x deploy.sh (ya chmod 755 deploy.sh)
  • Execution: ./deploy.sh

5. Process Management & Networking

  • sleep 1000 &: Background me process run karta hai.
  • ps aux | grep sleep: Running processes list karke PID nikalta hai.
  • kill -9 <PID>: Forcefully process terminate karta hai.
  • top: Real-time CPU, RAM aur task utilization monitor karta hai.
  • curl -I https://www.google.com: HTTP response status aur headers check karta hai.
  • ss -tuln: System par listening TCP/UDP sockets aur ports check karta hai.
  • ip addr show: where is ip a (private IP check karna)
