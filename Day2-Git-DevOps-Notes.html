3. Merge Conflicts: Anatomy & Resolution

  • Conflict Trigger: Jab do divergent branches par ek hi file ki same line ko modify karke merge kiya jata hai.
  • Conflict Markers:
    • <<<<<<< HEAD: Current checked-out branch ka version.
    • =======: Separator divider.
    • >>>>>>> <branch>: Incoming branch ka version.
  • Resolution Flow:
    1. VS Code me required changes select karo (Accept Incoming / Current / Both).
    2. File save karo (Ctrl + S).
    3. Resolved file ko stage karo: git add <file>.
    4. Merge commit record karo: git commit -m "fix: resolve merge conflict...".
  • Visual Inspection: git log --oneline --graph -n 5 branch divergence aur convergence ka ASCII graph show karta hai.

4. Remote GitHub Integration via SSH (Enterprise Standard)

  • SSH Keygen: ssh-keygen -t ed25519 -C "email" (Modern lightweight cryptographic key pair).
  • Key Separation:
    • Private Key: ~/.ssh/id_ed25519 (Confidential, machine ke andar safe rehti hai).
    • Public Key: ~/.ssh/id_ed25519.pub (GitHub profile settings me map hoti hai).
  • Test Auth: ssh -T git@github.com (Connection verification).
  • Link Remote: git remote add origin <SSH_URL>.
  • Track & Push: git push -u origin main (-u upstream tracking set karta hai).
