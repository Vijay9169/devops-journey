DevOps Engineering Handbook — Day 3 Notes (Part 1)

1. Docker Architecture & Core Concepts

  • Image vs Container: Image read-only blueprint hoti hai jisme application code, OS runtime, aur dependencies packed hoti hain. Container usi image ka ek isolated running instance (process) hota hai.
  • Docker Daemon: Background service (dockerd) jo images, containers, networks, aur storage volumes manage karti hai.

2. Essential Container Lifecycle Commands

CommandFlags / ArgsDescription
docker run-d -p 8080:80 --name <name>Image pull karke container ko detached mode (-d) me background me start karta hai aur host port 8080 ko container port 80 se map karta hai.
docker psNo flagSirf running containers ki list display karta hai.
docker ps -a-a (All)Running aur stopped (Exited) sabhi containers show karta hai.
docker logs<name>Container ke live logs (stdout/stderr) display karta hai.
docker exec -it-i (Interactive), -t (TTY)Running container ke andar shell (bash/sh) session open karta hai debugging ke liye.
docker stop<name>Container process ko graceful shutdown signal (SIGTERM) bhejta hai.
docker rm<name>Stopped container instance ko delete karke storage aur name release karta hai.
